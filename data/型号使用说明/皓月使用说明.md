# S8-LUNA 皓月使用说明

## 1. 型号定位

| 项目 | 说明 |
| --- | --- |
| 型号 | S8-LUNA 皓月 |
| 项目内建议价格 | 2999 元 |
| 已确认功能 | 静音运行、激光导航、自动集尘、拖布热风烘干 |
| 适合场景 | 80-140 平方米家庭、夜间清洁、婴幼儿家庭、希望降低维护频率的用户 |
| 不适合直接处理 | 大片积水、黏性垃圾、未收纳的电线和玩具、楼梯边缘无防护区域 |

皓月适合把日常清扫安排在固定时段。激光导航用于建图和分区，自动集尘与拖布热风烘干用于减少尘盒清理和拖布潮湿带来的维护负担。静音不代表无噪声，夜间首次运行仍应先观察是否会碰到家具或宠物用品。

## 2. 组件与功能

| 组件/功能 | 用途 | 使用要点 |
| --- | --- | --- |
| 激光导航组件 | 建图、定位和规划路线 | 顶部及周边保持清洁，镜面、强反光物或频繁搬动家具可能影响建图 |
| 主刷、边刷、吸口 | 将灰尘和毛发送入尘盒 | 清扫前先收起长电线；宠物家庭应更频繁检查毛发缠绕 |
| 尘盒和滤网 | 收集并过滤灰尘 | 尘盒满、滤网堵塞会导致吸力下降；清洗后必须完全晾干再装回 |
| 自动集尘座 | 将机身尘盒中的灰尘转移至集尘袋 | 集尘时有短时较大噪声；检查集尘袋和通道是否安装、畅通 |
| 拖地组件和烘干功能 | 完成湿拖并降低拖布潮湿时间 | 拖布脏污先清洗；木地板优先低水量，完成后确认拖布已干燥 |
| 充电触点和电池系统 | 供电、回充 | 机身与底座触点只用干软布擦拭，不可用湿布或腐蚀性液体 |

## 3. 首次使用与日常运行

1. 将集尘座靠墙放在干燥、平整的位置，电源线不要横跨机器人回充路径。
2. 装好主刷、边刷、尘盒和滤网。需要拖地时装好洁净拖布，并按设备提示加注清水。
3. 首次运行先执行建图或全屋清扫；过程中不要抱起、推动或频繁移动机器人。
4. 建图完成后按房间设置清扫顺序。婴幼儿房建议选择低噪时段和低水量拖地，地毯区应按控制端能力设置禁拖或清扫策略。
5. 完成任务后确认机器人回到集尘座；检查拖布是否需要清洗、烘干，必要时清理尘盒口和集尘通道。

## 4. 电池与充电

| 项目 | 使用说明 |
| --- | --- |
| 电池参数 | 容量、续航和充电时长以机身铭牌或正式规格书为准，本说明不设定数值 |
| 日常充电 | 任务结束后保持在已通电的充电座上；触点有灰尘时先断电再用干布清洁 |
| 长期不用 | 关闭设备后存放在阴凉干燥处，避免高温暴晒、低温冻存和长期完全亏电 |
| 异常处理 | 鼓包、漏液、明显发热、烧焦味或无法稳定充电时立即停用，勿自行拆解或更换非原装电池 |

## 5. 维护建议

| 频率 | 操作 |
| --- | --- |
| 每次任务后 | 清理主刷/边刷毛发，检查尘盒；使用拖地后清洗拖布并确认烘干流程完成 |
| 每周 | 擦拭激光导航区域、沿边和防跌落传感器；检查集尘通道和充电座周围是否有堵塞 |
| 每月 | 检查滤网、轮组、万向轮、拖布支架和充电触点；按设备提示检查集尘袋状态 |

## 6. 常见问题与处理

| 现象 | 先检查 | 可执行处理 | 停止使用/联系售后条件 |
| --- | --- | --- | --- |
| 找不到充电座 | 底座是否通电、回充路径是否被遮挡、触点是否脏污 | 清理底座周围和触点，将机器人放回附近重新发起回充 | 多次无法回充或底座无指示时 |
| 集尘后仍提示尘盒满 | 集尘袋、尘盒口和集尘通道是否堵塞 | 断电后重新安装集尘袋，清理可见灰尘和毛发 | 集尘座持续异响、发热或无吸力时 |
| 拖布有异味或未干 | 拖布是否过脏、烘干通风口是否被挡 | 清洗拖布、清理通风区域并重新执行烘干 | 烘干异常发热、有焦味时 |
| 地图错乱或漏扫 | 激光区域是否脏污、家具是否大幅移动 | 擦拭传感器，移除反光/临时障碍物后重新建图 | 传感器破损或反复建图失败时 |
| 夜间噪声变大 | 主刷、边刷、轮组和集尘通道是否缠绕 | 清理毛发杂物，避开自动集尘时段或调整任务时间 | 清理后仍有尖锐摩擦声或机身发热时 |
| 吸力下降 | 尘盒、滤网、吸口和主刷是否堵塞 | 按顺序清洁并装回完全干燥的滤网 | 风机异响、持续报错时 |

## 7. 型号专属安全使用

通用电气、电池、进水和儿童宠物规范见[通用安全与维护规范](通用安全与维护规范.md)。皓月还应特别注意：

| 风险点 | 安全要求 |
| --- | --- |
| 自动集尘时段 | 集尘会产生短时高噪声，不安排在婴幼儿睡眠、宠物紧张或需要安静的时段；集尘中不要拆开尘盒或集尘袋仓 |
| 集尘座通道 | 不要把纸巾、塑料袋、长发团等故意放入吸口；通道堵塞时断电后只清理可见异物，不用尖锐金属物深入内部 |
| 拖布热风烘干 | 烘干口保持通风，不覆盖衣物、纸张或软垫；闻到焦味、异常烫手或烘干反复失败时立即断电 |
| 夜间任务 | 激光导航和低噪模式均不能替代地面收纳；夜间定时前要确认儿童房、宠物用品和充电线已避开任务路径 |
