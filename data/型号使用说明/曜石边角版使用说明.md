# X9-EDGE 曜石 Edge 使用说明

## 1. 型号定位

| 项目 | 说明 |
| --- | --- |
| 型号 | X9-EDGE 曜石 Edge |
| 项目内建议价格 | 3599 元 |
| 已确认功能 | 贴边清洁、毫米级障碍物识别、强吸力、地毯增压 |
| 适合场景 | 家具较多、墙角灰尘明显、养宠家庭、地毯与硬地面混合环境 |
| 使用重点 | 清理细线、小件和宠物排泄物；根据地毯和边角情况配置清扫策略 |

贴边能力和障碍物识别用于提高覆盖率与减少碰撞，但不代表可以识别所有透明、反光、极低矮或被遮挡的物品。地面杂物收纳仍是安全和清洁效果的前提。

## 2. 组件与功能

| 组件/功能 | 用途 | 使用要点 |
| --- | --- | --- |
| 贴边清洁系统 | 提升墙边、桌腿和边角区域的覆盖 | 边刷、沿边传感器保持清洁；墙角堆积物仍可能需要人工处理 |
| 障碍物识别组件 | 在家具和杂物较多的环境中辅助绕行 | 识别能力受光线、污渍、透明物和遮挡影响，不要依赖它处理电线或宠物排泄物 |
| 强吸力清扫系统 | 处理颗粒物、毛发和地毯浮灰 | 吸力提高时噪声和能耗通常增加，按场景使用而非全程高档 |
| 地毯增压 | 在地毯上强化清扫 | 先固定地毯边缘和流苏；厚地毯、长毛地毯是否可通过以实际表现为准 |
| 刷组、尘盒、滤网 | 灰尘收集与过滤 | 宠物家庭须高频清理，避免毛发缠绕导致吸力下降 |

## 3. 推荐使用方式

1. 家具密集区域先收起数据线、鞋带、薄塑料袋、宠物玩具和小件；桌椅腿间距过窄的区域可设置禁区。
2. 建图后检查边角和门口是否被正确识别。对灰尘较多的墙边区域设置定点或重复清扫。
3. 地毯区域启用可用的地毯清扫策略；拖地需求与地毯共存时，优先避免湿拖进入地毯。
4. 宠物换毛季按实际效果增加清扫频次，任务后优先清理主刷、边刷、吸口与滤网。
5. 夜间使用如需降低噪声，选择合适时段或较低档位；不要在无人状态下让设备处理地面杂物复杂的区域。

## 4. 电池与充电

| 项目 | 使用说明 |
| --- | --- |
| 电池参数 | 容量、充电时间和可用面积未在型号目录中确认，以设备显示和正式规格书为准 |
| 高负载场景 | 地毯增压、强吸力和高频重复清扫可能增加耗电，任务中回充应结合控制端提示判断 |
| 充电维护 | 定期用干软布擦拭机身和充电座触点，保持回充路径平整、无杂物 |
| 异常 | 续航骤降、反复断充、发热或异味时停止使用并检查电池与适配器提示 |

## 5. 维护建议

| 频率 | 操作 |
| --- | --- |
| 每次任务后 | 清除主刷、边刷、吸口和轮组毛发；检查尘盒是否需要清空 |
| 每周 | 擦拭障碍物识别、沿边和防跌落区域；清洁地毯纤维残留 |
| 每月 | 检查滤网完整性、边刷磨损、轮组转动及充电触点状态 |

## 6. 常见问题与处理

| 现象 | 先检查 | 可执行处理 | 停止使用/联系售后条件 |
| --- | --- | --- | --- |
| 沿墙仍漏扫 | 边刷磨损、沿边区域是否被堆放物遮挡 | 清洁/更换边刷，移开障碍后安排沿边补扫 | 边刷不转或传感器外观损坏时 |
| 频繁碰撞家具 | 识别区域是否有灰尘、水渍，环境是否光线过暗 | 擦拭传感器，改善照明，收起透明/低矮小件 | 清洁后仍持续撞击或防撞条卡死时 |
| 地毯清扫效果差 | 地毯增压设置、主刷和风道、地毯边缘 | 清理刷组，固定流苏，按控制端启用地毯策略 | 电机异响、反复卡在地毯上时 |
| 宠物毛发缠绕 | 主刷两端、边刷和轮轴 | 停机后用清洁工具切断并移除毛发，提高清扫频率 | 刷组无法复位或电机过热时 |
| 强吸力时噪声异常 | 风道、滤网、尘盒和刷组 | 清理堵塞并检查安装是否到位 | 清理后仍有尖锐异响、焦味或发热时 |
| 误绕开正常区域 | 地面镜面、强反光、临时物品和地图 | 移开反光/临时障碍物，复扫该区域或更新地图 | 大面积无法清扫且反复报传感器错误时 |

## 7. 型号专属安全使用

通用电气、电池、进水和儿童宠物规范见[通用安全与维护规范](通用安全与维护规范.md)。曜石 Edge 的重点风险在识别依赖和高负载清扫：

| 风险点 | 安全要求 |
| --- | --- |
| 障碍物识别 | 透明物、镜面、细线、低矮小件和宠物排泄物可能超出识别边界，必须人工收纳，不能把“毫米级识别”当作安全保证 |
| 强吸力模式 | 启动前移除耳环、积木、硬币、纸片和易卷入织物；高吸力时不要让儿童宠物靠近吸口 |
| 地毯增压 | 固定长流苏和松动边缘，避免设备卷入后拖拽地毯；厚地毯反复卡住时将该区域设为禁区 |
| 贴边清扫 | 不要把手指伸入靠墙运行区域或试图在运行中取出边刷缠绕物，必须先暂停、断电后处理 |
