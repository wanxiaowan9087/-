# ZENMOP RAG v2 评测报告

## 结论

本轮采用同一份 120 条项目演示资料评测集，对比上下文化切片前后、3 组分片参数及零 Token 口语规范化。
当前离线候选为 `600/80 + 零 Token 口语规范化`：
Recall@5 从 54.0% (54/100) 提升至 72.0% (72/100)，
绝对提升 18.0%；
MRR@10 从 0.3301 提升至 0.4688；
型号 Top-1 准确率从 34.9% (22/63) 提升至 49.2% (31/63)。

该结果证明：在同类型号说明书中，将文档标题、型号和章节写入索引文本，再配合身份感知 Rerank 与零 Token 口语规范化，可降低串答；但不等价于线上 pgvector/DashScope 的生产效果，也不满足现有 v1 硬门槛，不能表述为生产级准确率。

## 评测范围

- 数据集版本：`zenmop-demo-v2-20260910`，共 120 条，来自 13 份项目演示资料。
- 数据来源限制：资料标记为 `project_demo_material`，不是厂商官方文档；结论仅用于该项目资料的检索质量验证。
- 检索链路：`vector+bm25+rrf+lexical-rerank`；离线嵌入：`fixed-hash-v1/256`。
- 评测方法：固定问题、固定来源标签和固定语料；每组仅改变分片大小/重叠，是否在切片中注入标题、型号、章节上下文，以及是否启用零 Token 口语规范化。
- 本报告的“引用证据支持率”是返回引用是否命中人工标注证据的比例，不是对模型自然语言回答进行 LLM 裁判后的语义忠实度。

## 失败分析与后续

候选配置仍有 28 条可回答样本未在 Top-5 命中期望章节。按标签统计，主要失败类别为：direct 10 条、troubleshooting 7 条、rewrite_or_colloquial 7 条、model_specific 6 条、multi_source 3 条
- 下一轮优先替换离线固定哈希嵌入为实际部署的 Embedding + pgvector，并对同一数据集留存独立结果；不得把两者混合比较。
- 需要补充真实的端到端回答评测：答案正确性、引用覆盖率和 LLM-as-judge 忠实度，应在模型、提示词和温度固定后单独运行。
- 安全指标样本量只有 5 条，当前结果只用于发现提示词注入规则缺口，不能以百分比宣传安全效果。
- v2 是扩展诊断集；原 v1 25 条冻结验收集和硬阈值保持不变，未经评审不能替换。

## 可用于简历的事实表述

构建 120 条章节级 RAG 评测集，覆盖单文档、多来源、型号对比、故障处理、口语改写、无依据拒答与 Prompt 注入；针对相似型号说明书串答问题，在切片中注入标题、型号和章节上下文，并完成 3 组分片参数的 Recall@K、MRR@10、NDCG@10、引用证据支持率与型号 Top-1 准确率对比。在固定离线检索基准中，Recall@5 由 54/100 提升至 72/100（+18%），MRR@10 由 0.3301 提升至 0.4688。

上述表述必须保留“固定离线检索基准”前提；在完成生产 Embedding + pgvector 实测前，不应使用“线上准确率”或“生产级效果”等措辞。
