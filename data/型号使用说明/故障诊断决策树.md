# ZENMOP 故障诊断决策树

## 0. 安全优先

出现冒烟、烧焦味、电池鼓包/漏液、异常发热、机身或基站进水、持续漏水时，立即停止任务、断开电源并联系售后。不要为了继续排查而拆电池、主板、水泵或电机。

## 1. 通用决策路径

```text
出现异常
  ├─ 有安全红线？ -> 立即停用，记录现象和设备状态，联系售后
  └─ 无安全红线
      ├─ 无法开机/充电？ -> 电源、触点、轮组停稳、电池提示
      ├─ 无法移动/频繁卡住？ -> 轮组、门槛、线缆、地毯边、禁区
      ├─ 清扫效果下降？ -> 尘盒、滤网、吸口、主刷/边刷、模式
      ├─ 拖地异常？ -> 水量、拖布、水箱/水路、地面材质
      ├─ 地图/避障异常？ -> 传感器、光线、反光物、家具变化
      └─ 控制端异常？ -> 网络、账号、设备绑定、地图同步、固件提示
```

## 2. 标准排查表

| 症状 | 第一检查 | 用户可做的处理 | 仍异常时应记录 |
| --- | --- | --- | --- |
| 开机无反应 | 充电座供电、开关、电池提示 | 重新放回底座，确认触点干燥；等待设备提示后重试 | 指示灯状态、最近一次使用时间 |
| 无法回充 | 底座位置、回充路径、触点和传感器 | 移除障碍，擦拭触点和传感器，把设备放到底座前测试 | 是否每次都在同一位置失败 |
| 不移动/原地打转 | 驱动轮、万向轮、底盘异物 | 停机断电后清理毛发和硬物，重新放在平整地面 | 轮组是否有卡顿或异响 |
| 吸力下降 | 尘盒、滤网、吸口、刷组 | 清空尘盒，清理并完全晾干滤网，拆除毛发 | 清理前后声音与吸力变化 |
| 主刷/边刷不转 | 卡扣、毛发、异物 | 断电后拆下清理并重新安装 | 是否伴随电机报错 |
| 拖布不湿/不出水 | 水箱水量、出水设置、拖布安装 | 加清水，确认拖布卡紧，按设备允许范围清理出水口 | 是否漏水、是否仅某个分区发生 |
| 地面水痕 | 出水量、拖布洁净度、材质 | 清洗拖布、降低水量，木地板先改为仅扫 | 地面材质和水痕位置 |
| 地图错乱/漏扫 | 传感器、设备是否被搬动、家具变化 | 清洁传感器，恢复底座位置，必要时重新建图 | 地图版本和发生时间 |
| 频繁碰撞 | 传感器污渍、反光/透明物、照明 | 清洁传感器，移开镜面和细小物品 | 物品类型和房间光线 |
| APP 离线 | 路由器、配网状态、账号 | 按设备流程重新配网，重启路由器和设备 | 错误提示和网络频段 |

## 3. 关闭工单条件

只有在现象消失、没有安全风险、设备能完成一次受控测试并且用户知道后续维护动作时，才能标记为“已解决”。涉及电池、主板、电机、水泵、持续漏水或关键传感器的故障，不应通过远程文字指导自行拆修。
