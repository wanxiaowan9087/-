# M6-TERRA 霞陶使用说明

## 1. 型号定位

| 项目 | 说明 |
| --- | --- |
| 型号 | M6-TERRA 霞陶 |
| 项目内建议价格 | 2499 元 |
| 已确认功能 | 高扭矩滚刷、可调水量、木地板保护、分区清洁 |
| 适合场景 | 木地板与瓷砖混合地面、重视地面护理的家庭 |
| 使用重点 | 按地面材质设置水量和分区，避免木地板积水和滚刷长期缠绕 |

霞陶的核心是混合地面护理。木地板保护不代表所有木地板都可高水量拖地；受潮敏感、开裂、起翘或未做防水处理的地板应优先仅扫或低水量拖地，并遵循地板厂商护理要求。

## 2. 组件与功能

| 组件/功能 | 用途 | 使用要点 |
| --- | --- | --- |
| 高扭矩滚刷 | 提升地面碎屑、毛发和缝隙灰尘的卷入能力 | 毛发、线头和地毯纤维容易缠绕，清理前先断电 |
| 可调水量拖地组件 | 按区域控制湿拖程度 | 木地板低水量，瓷砖可按污渍情况调整；不可让地面积水 |
| 木地板保护策略 | 减少湿拖对木地板的风险 | 需结合实际地板状态和控制端可用设置，发现水痕立即降低水量 |
| 分区清洁 | 为不同房间设置不同任务 | 建议将木地板、瓷砖、厨房和玄关分开设置，避免一套参数全屋通用 |
| 尘盒、滤网和轮组 | 收集灰尘并保证行走 | 定期清理，防止滚刷负载上升和吸力下降 |

## 3. 推荐使用方式

1. 首次建图后将木地板房间、瓷砖房间、厨房和玄关分区命名。
2. 先在小范围试运行：木地板使用低水量或仅扫地，确认无水痕后再安排整屋任务。
3. 厨房或玄关有明显油污、泥沙时先人工清理大块污渍，再使用分区重复清扫或拖地。
4. 高扭矩滚刷适合处理日常碎屑和毛发，但硬币、螺丝、玻璃等硬物必须先手动移除。
5. 清扫结束后及时清洗拖布、倾倒污水或排空水箱中的剩水，保持水路干净。

## 4. 电池与充电

| 项目 | 使用说明 |
| --- | --- |
| 电池规格 | 未在型号目录中确认，容量、续航与充电时间以铭牌和正式规格书为准 |
| 日常使用 | 保持回充，避免长时间完全亏电；任务中因低电量回充后是否续扫以设备提示为准 |
| 长期存放 | 清空水箱，清洗并晾干拖布，关闭设备后置于阴凉干燥处 |
| 异常处理 | 充电异常、鼓包、漏液、异味或异常发热时立即停用，不可自行拆开电池仓 |

## 5. 维护建议

| 频率 | 操作 |
| --- | --- |
| 每次拖地后 | 清洗拖布，倒掉剩水，检查水箱盖和密封部位；观察木地板是否有水痕 |
| 每次清扫后 | 清理高扭矩滚刷两端、吸口和尘盒，移除毛发与线头 |
| 每周 | 擦拭传感器和充电触点，检查轮组、拖布支架和水路接口 |
| 每月 | 检查滤网、滚刷胶条或刷毛的磨损状态；确认分区地图仍与家具布局匹配 |

## 6. 常见问题与处理

| 现象 | 先检查 | 可执行处理 | 停止使用/联系售后条件 |
| --- | --- | --- | --- |
| 木地板出现水痕 | 水量设置、拖布洁净度、地板是否已受潮 | 立即擦干，改为低水量或仅扫地，保持通风 | 地板起翘/变色或水箱持续漏水时 |
| 滚刷卡住或打滑 | 毛发、线头、地毯纤维和硬物 | 断电后拆下滚刷清理，检查两端安装到位 | 滚刷变形、轴承异响或电机无法转动时 |
| 拖地不出水 | 水箱是否有水、出水设置、水路是否可见堵塞 | 加注清水，确认水量设置，按可见部位清洁 | 水箱渗漏、泵异常或反复报错时 |
| 瓷砖缝仍脏 | 清扫次数、水量、拖布状态 | 清洗/更换拖布，针对该分区增加清洁次数 | 不要用腐蚀性清洁剂或尖锐工具处理水路 |
| 分区任务执行错误 | 地图分区、房间名称、禁区和设备位置 | 检查并保存地图设置，必要时重新建图 | 地图持续丢失或无法保存时 |
| 清扫后有毛絮 | 拖布掉毛、滚刷磨损、滤网装配 | 清洗或更换拖布，检查滚刷和滤网安装 | 配件破损或反复出现异常残留时 |

## 7. 型号专属安全使用

通用电气、电池、进水和儿童宠物规范见[通用安全与维护规范](通用安全与维护规范.md)。霞陶的重点风险在地面材质和水量管理：

| 风险点 | 安全要求 |
| --- | --- |
| 木地板湿拖 | 未确认耐水性的木地板、已经起翘/开裂的地板和地板缝隙区域只做扫地或人工护理，不以“木地板保护”替代现场判断 |
| 可调水量 | 首次对每种地面材质做小范围试拖；发现水痕、积水或边缝受潮，立即降低水量并擦干地面 |
| 高扭矩滚刷 | 硬币、螺丝、玻璃、宠物玩具和长线缆会造成卡死或抛飞风险，必须在运行前清走 |
| 清洁液 | 木地板清洁剂只有在正式说明确认兼容时才可使用；任何有刺激性气味、腐蚀性或起泡液体均不得加入水路 |
