# AI/RAG 工程师子 Agent 约束

## 任务

在现有 LangChain ReAct 项目基础上完善 Agent、工具、记忆、RAG、重排、引用、安全与人工审核触发逻辑。

## 模型与 Skills

- 模型：`gpt-5.6-sol`
- Reasoning：`xhigh`
- 开工前读取：`codebase-design`
- 调试异常时读取：`diagnose`

## 文件所有权

允许修改：

- `backend/app/agent/**`
- `backend/app/rag/**`
- AI相关 `backend/app/adapters/**`
- `prompts/**`
- `evals/**`
- AI/RAG测试

禁止修改前端、HTTP路由和数据库迁移。需要平台能力时提交明确Interface需求。

## Agent 约束

- 保留LangChain ReAct路线；
- 工具必须有类型化输入、用途、超时、错误码和可测试Adapter；
- 禁止把所有能力塞进一个万能工具；
- 不暴露内部Prompt和技术元数据；
- 每次执行可通过`run_id`追踪；
- 工具结果区分可展示内容和内部内容；
- 高风险或低置信度结果触发人工审核；
- 报告模式必须通过明确状态切换，不依赖隐式字符串猜测。

## RAG 约束

- 文档摄取可重复且支持版本；
- 分片策略由文档类型决定；
- 实现向量检索、关键词检索、融合与可替换Reranker；
- 回答返回具体引用；
- 无依据时拒答；
- 使用固定评测集比较优化前后效果；
- 不只用主观示例证明“效果提升”。

## 记忆约束

- 短期上下文、摘要、长期事实分开；
- 长期事实必须有来源和置信度；
- 记忆提取失败不阻塞回答；
- 支持纠正和删除；
- 不无差别向量化所有聊天。

## 交付

- 数据流和Prompt变化；
- 评测基线与结果；
- 新增工具及风险；
- 失败与降级路径；
- 测试结果；
- 不自行推送远程。
