# ZENMOP 首次安装与建图指南

## 1. 安装前检查

| 检查项 | 合格状态 |
| --- | --- |
| 地面 | 干燥、平整，无大面积积水、玻璃、药品、宠物排泄物和易卷入线缆 |
| 充电座/基站 | 靠墙、稳定、通风，回充通道没有门、箱子或高差阻挡 |
| 设备 | 主刷、边刷、尘盒、滤网、拖布或水箱按型号配置装好 |
| 网络与控制端 | 按项目支持的配网流程完成绑定，不在公共网络中暴露管理凭据 |
| 安全区域 | 楼梯口、阳台边、儿童活动区、宠物食盆和潮湿区域已设置禁区或物理隔离 |

## 2. 建图流程

1. 让设备从充电座出发，首次运行期间不要抱起、推动或中途更换底座位置。
2. 保持主要房门打开，先完成可控的建图/探索流程；不要用临时箱子或人体堵住通道。
3. 建图结束后检查房间边界、门口连接、充电座位置和明显不可通行区域。
4. 将地图分区命名，分别标记木地板、瓷砖、地毯、厨房、宠物窝和禁拖区。
5. 先对一个小分区做清扫测试，再启用全屋、定时或多次清扫。

## 3. 型号设置重点

| 型号 | 建图/首次测试重点 |
| --- | --- |
| S8-LUNA 皓月 | 观察激光建图和回充；测试自动集尘、拖布烘干是否正常并安排合适时段 |
| S8-AIR 轻羽 | 重点测试床底、桌椅腿和窄门口的通行；不要因机身轻薄而跳过测试 |
| X9-OBSIDIAN 曜石 | 验证多房间地图、地毯识别、双旋拖布及水路安装后的漏水状态 |
| X9-EDGE 曜石 Edge | 在家具密集、边角和地毯区域做受控测试，确认识别边界和增压策略 |
| M6-TERRA 霞陶 | 分别在木地板和瓷砖小范围试拖，建立不同水量和清洁次数配置 |
| M6-MINI 小径 | 重点测试定时任务、卧室通道、门槛和充电路径，确认无人任务不会卡困 |

## 4. 建图异常处理

地图错乱时先确认设备没有被搬动、底座没有移动、传感器没有污渍；清理并恢复环境后再尝试定位或重新建图。不要连续删除地图重建而不记录每次环境变化，否则无法判断问题来自硬件、环境还是配置。
