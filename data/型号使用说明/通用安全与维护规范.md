# ZENMOP 通用安全与维护规范

本规范适用于 `型号使用说明` 目录中的全部 ZENMOP 型号。型号文档仅补充其专属风险和操作差异，不重复本页内容。

## 1. 必须遵守的安全要求

| 场景 | 必须执行 | 禁止行为 |
| --- | --- | --- |
| 运行前 | 收起电线、药品、玻璃碎片、小玩具、宠物排泄物和大面积液体；检查楼梯口和阳台边缘 | 依赖避障功能处理全部地面杂物 |
| 充电 | 使用匹配的充电座和电源，保持触点、插头和地面干燥 | 湿手插拔电源、使用破损线缆或非适配电源 |
| 清洁维护 | 停止任务并断开电源后再拆装刷组、滤网、拖布或水箱 | 直接冲洗机身、将水或清洁液倒入非水路部位 |
| 儿童与宠物 | 首次运行有人看管；设置禁区覆盖宠物食盆、儿童玩具区和楼梯口 | 让儿童或宠物坐在、触摸或追逐运行中的设备 |
| 水路与清洁液 | 仅加清水或正式说明允许的适配液体，并按指引稀释 | 使用酒精、消毒液、强酸碱、洗洁精或未经确认的液体 |
| 存放 | 清空尘盒和水箱、晾干拖布，放在阴凉干燥处 | 高温暴晒、潮湿存放、长期完全亏电 |

## 2. 必须立即停用的情况

出现下列任一情况，立即停止任务、关闭设备和充电座电源，移至安全干燥位置，并联系正式售后或维修渠道：

- 电池鼓包、漏液、异常发热、烧焦气味、冒烟或外壳变形。
- 机身、基站、电源适配器或插座进水；充电触点变色、烧蚀、持续断充。
- 主刷、轮组或拖布电机持续异响、卡死，清理可见异物后仍不能恢复。
- 水箱、基站或上下水接口持续渗漏、污水回流，或水渍接近电气部位。
- 防跌落、避障、充电、地图等关键功能反复报错，已按型号说明完成基础检查仍未解决。

## 3. 通用维护节奏

| 频率 | 项目 |
| --- | --- |
| 每次任务后 | 清理尘盒、主刷、边刷、吸口和轮组毛发；有拖地功能时清洗拖布并处理剩水/污水 |
| 每周 | 擦拭传感器、防撞条、充电触点；检查电源线、底座位置与回充通路 |
| 每月 | 检查滤网、刷组、轮组、密封件和水路可见部位；根据磨损和设备提示更换耗材 |
| 长期停用前 | 完成清洁、排空水箱、晾干耗材、确认电池状态并按设备正式说明存放 |

## 4. 参数边界

本目录不将通用文章中的电池循环次数、滤网更换月数、充电时长、水箱容量或越障能力当作六款 ZENMOP 型号的已确认参数。所有数值以对应设备铭牌、包装清单、控制端提示和正式规格书为准。
