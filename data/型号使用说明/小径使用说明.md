# M6-MINI 小径使用说明

## 1. 型号定位

| 项目 | 说明 |
| --- | --- |
| 型号 | M6-MINI 小径 |
| 项目内建议价格 | 1599 元 |
| 已确认功能 | 紧凑机身、低噪扫拖、简单分区、定时任务 |
| 适合场景 | 40 平方米以内、单身公寓、卧室、低成本日常自动清洁 |
| 使用重点 | 简化任务、保持地面收纳、定期清理尘盒和拖布 |

小径适合小空间的高频日常维护。低噪扫拖适合卧室或公寓作息，但不应在熟睡、婴幼儿活动或宠物紧张时段无监督运行。

## 2. 组件与功能

| 组件/功能 | 用途 | 使用要点 |
| --- | --- | --- |
| 紧凑机身 | 适应公寓和卧室内的常见通道 | 狭窄区域仍需实测，门槛、床底和家具脚可能造成卡困 |
| 低噪扫拖 | 支持日常轻度灰尘与污渍维护 | 不等于静音；较脏区域应优先处理大颗粒和黏性污渍 |
| 简单分区 | 对卧室、客厅或玄关安排独立任务 | 分区前先确保地图完整，家具位置变化后检查任务范围 |
| 定时任务 | 在固定时间自动执行 | 仅在地面已收纳、宠物/儿童安全安排妥当时启用 |
| 尘盒、滤网、刷组、拖布 | 执行扫拖和过滤 | 小型机身不代表无需维护，满尘和缠绕会降低效果 |

## 3. 推荐使用方式

1. 在首次运行前清走充电线、耳机线、袜子、薄塑料袋和桌椅脚附近的小物件。
2. 先完成一次有人看管的全屋/单房间清扫，观察门槛、床底和地毯边是否可顺利通过。
3. 对卧室、客厅和玄关建立简单分区；将定时任务安排在外出或非休息时段。
4. 轻度拖地使用洁净拖布和适量清水。木地板、地板缝隙和潮湿区域优先低水量或仅扫地。
5. 每次任务后清空尘盒、摘除刷组毛发；拖地后拆下拖布清洗并自然晾干。

## 4. 电池与充电

| 项目 | 使用说明 |
| --- | --- |
| 规格边界 | 电池容量、充电时长和续航未在型号目录中确认，以设备实际信息为准 |
| 定时任务前 | 确认底座已通电、触点清洁、机器人可正常回充，避免低电量启动后中断 |
| 长期不使用 | 清理尘盒和水箱，清洗晾干拖布后关闭存放，避免高温、潮湿和完全亏电 |
| 异常 | 若频繁自动关机、无法充电、电池鼓包或有异味，立即停止使用 |

## 5. 维护建议

| 频率 | 操作 |
| --- | --- |
| 每次任务后 | 倒掉尘盒垃圾，清理主刷/边刷毛发；拖地后清洗拖布 |
| 每周 | 擦拭传感器、防撞条、充电触点，检查轮组是否被头发和线头缠绕 |
| 每月 | 检查滤网干燥度与磨损，确认定时任务、分区和禁区仍符合房间布局 |

## 6. 常见问题与处理

| 现象 | 先检查 | 可执行处理 | 停止使用/联系售后条件 |
| --- | --- | --- | --- |
| 定时任务未执行 | 底座供电、网络/控制端状态、任务开关和时间设置 | 重新保存任务，确认设备未处于故障或离线状态 | 多次无法执行并伴随设备报错时 |
| 卧室清扫噪声偏大 | 刷组、轮组、尘盒和地面硬物 | 清理缠绕物和硬物，调整任务时间 | 清理后仍有刺耳异响或发热时 |
| 卡在家具下或门槛 | 可通过高度、地毯边、线缆和家具间距 | 移除障碍，设置禁区或调整家具摆放 | 底盘、轮组受损或反复脱困失败时 |
| 地面仍有碎屑 | 尘盒、滤网、主刷和吸口 | 清理堵塞，增加该分区清扫频率或补扫 | 吸力持续异常、风机不转时 |
| 拖布有异味/水痕 | 拖布是否脏、出水设置、是否长期未晾干 | 清洗晾干拖布，降低水量，保持通风 | 水箱漏水、异味伴随机身进水时 |
| 无法连接控制端 | 配网状态、网络频段、密码和控制端版本 | 按设备提示重新配网，重启设备和路由器 | 反复失败或出现硬件网络模块报错时 |

## 7. 型号专属安全使用

通用电气、电池、进水和儿童宠物规范见[通用安全与维护规范](通用安全与维护规范.md)。小径的重点风险在定时无人任务和单身公寓杂物环境：

| 风险点 | 安全要求 |
| --- | --- |
| 定时任务 | 每次离家前确认地面没有电线、袜子、纸巾、宠物用品和小件；定时功能不能替代收纳检查 |
| 卧室与休息区 | 不在熟睡、婴幼儿活动或宠物高度紧张时无监督运行；低噪模式不能消除轮组和吸口风险 |
| 小空间卡困 | 浴室门口、阳台边、楼梯口和家具底部必须进行通行测试；有积水、潮气或落差的区域设禁区 |
| 轻度拖地 | 地垫下、插座边、木地板缝隙和通风不佳区域不做湿拖，避免水渍滞留 |
