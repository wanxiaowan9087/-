## 推荐决策

| 用户问题 | 优先查看 |
| --- | --- |
| 需要少倒尘、拖布不易潮湿 | S8-LUNA 皓月 |
| 主要清洁小户型和卧室 | S8-AIR 轻羽或 M6-MINI 小径 |
| 多房间、地毯、宠物和自动水路 | X9-OBSIDIAN 曜石 |
| 墙边、家具腿和地毯灰尘较多 | X9-EDGE 曜石 Edge |
| 木地板与瓷砖需要不同水量 | M6-TERRA 霞陶 |

## 不能从表中推断的参数

电池容量、充电时长、吸力数值、机身高度、越障高度、尘盒/水箱容量、耗材寿命、IP 等级和支持的第三方清洁液均未在项目型号目录中确认。回答相关问题时必须提示用户查看铭牌、控制端或正式规格书。
