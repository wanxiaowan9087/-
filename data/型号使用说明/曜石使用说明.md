# X9-OBSIDIAN 曜石使用说明

## 1. 型号定位

| 项目 | 说明 |
| --- | --- |
| 型号 | X9-OBSIDIAN 曜石 |
| 项目内建议价格 | 4299 元 |
| 已确认功能 | 全屋激光建图、双旋拖布、地毯识别、自动上下水接口 |
| 适合场景 | 120-220 平方米家庭、多房间、宠物家庭、高频深度清洁 |
| 使用重点 | 先完成全屋建图，再按房间、地毯和拖地需求配置清洁策略 |

曜石面向大户型和多房间环境。自动上下水是“接口能力”，不代表任何家庭都已经具备安装条件；水路安装、排水位置和电气安全必须以正式安装要求为准。

## 2. 组件与功能

| 组件/功能 | 用途 | 使用要点 |
| --- | --- | --- |
| 全屋激光建图 | 创建房间地图、支持分区清扫 | 首次建图期间不要搬动机器人；家具大幅变化后应检查地图 |
| 双旋拖布 | 提升湿拖覆盖和去污能力 | 拖布应保持洁净，地毯区域要按控制端能力设置抬升、禁拖或绕行策略 |
| 地毯识别 | 区分地毯与硬地面 | 识别不替代人工检查；长流苏、松动边缘和薄地毯应提前固定或设为禁区 |
| 自动上下水接口 | 支持对接基站水路方案 | 未完成合规安装前按普通水箱/基站流程维护，严禁私接水管 |
| 尘盒、刷组、轮组 | 清扫与行走 | 宠物家庭重点清理毛发，避免刷组和集尘通道堵塞 |
| 充电与传感器组件 | 回充、定位、避障 | 传感器和底座触点保持干燥、无污渍 |

## 3. 首次设置

1. 将基站放置在通风、干燥、可稳定供电的位置；若计划使用上下水接口，先完成正式安装和漏水检查。
2. 先收起宠物食盆、排泄物、玩具、电线和易吸入物。为楼梯口、宠物窝和临时堆放区建立禁区。
3. 执行全屋建图。建图结束后检查房间分割、门口连接和充电座位置是否正确，再重命名房间。
4. 对地毯设置仅扫、禁拖或其他可用策略；对厨房、玄关等易脏区域设置更高频次或多次清洁。
5. 首次双旋拖布运行后检查地面水痕和拖布状态，按地面材质调整水量与清洁次数。

## 4. 电池、基站与水路

| 项目 | 使用说明 |
| --- | --- |
| 电池规格 | 容量、循环次数和充电时长未在型号目录中确认，以铭牌和正式规格书为准 |
| 日常回充 | 保持充电座供电和触点清洁；大户型任务中自动回充后继续清扫属于正常策略，具体行为以设备提示为准 |
| 清水/污水维护 | 使用后及时处理污水和拖布，不让污水长期存留；未确认支持的液体不得加入水路 |
| 上下水接口 | 仅由符合要求的安装方案接入；发现渗水、异味、回流或接口松动时立即停止用水功能 |

## 5. 维护建议

| 频率 | 操作 |
| --- | --- |
| 每次深度清洁后 | 清理主刷、边刷、尘盒和双旋拖布；检查地毯纤维与宠物毛发 |
| 每周 | 擦拭激光和防跌落传感器，清洁基站可见的水渍、毛发和集尘口 |
| 每月 | 检查轮组、拖布支架、密封件、进排水连接部位及滤网状态 |

## 6. 常见问题与处理

| 现象 | 先检查 | 可执行处理 | 停止使用/联系售后条件 |
| --- | --- | --- | --- |
| 多房间地图缺失或串房 | 房门是否关闭、激光组件是否脏、是否在建图时搬动设备 | 清洁传感器，打开房门后重新建图或修正分区 | 多次无法完成建图或地图持续丢失时 |
| 地毯被拖湿 | 地毯策略、拖布状态、地毯边缘识别 | 将该区域设为禁拖/仅扫，固定流苏并重新运行 | 多次误拖且无法配置时 |
| 双旋拖布不转 | 拖布是否缠绕、支架是否安装到位 | 断电后清理并重新安装，确认卡扣到位 | 拖布电机异响、支架破损时 |
| 上下水区域漏水 | 接口、软管、污水容器和密封件 | 立即停止拖地和用水，关闭相关水源，擦干可见积水 | 任何持续渗漏、回流或电气部位受潮情况 |
| 宠物毛发清不净 | 主刷、集尘通道、滤网是否堵塞 | 清理刷组和通道，提高相关房间的清扫频率 | 风机过热、集尘持续失败时 |
| 反复回充未完成任务 | 电池提示、底座位置、房间门和地图 | 检查回充通路，确认任务设置与可用面积 | 充电不稳定、异常发热或电池报错时 |

## 7. 型号专属安全使用

通用电气、电池、进水和儿童宠物规范见[通用安全与维护规范](通用安全与维护规范.md)。曜石的重点风险在水路和大户型自动化：

| 风险点 | 安全要求 |
| --- | --- |
| 自动上下水接口 | 仅使用正式安装方案，不自行加长、改接或打孔接水；接口附近不得摆放插线板、延长线或易燃物 |
| 基站水路 | 每次首次启用和搬动基站后检查渗水；发现污水回流、地面积水或接口松动，立即停止用水功能 |
| 多房间自动任务 | 大户型定时清扫前逐房检查宠物食盆、儿童玩具、地毯流苏和门是否处于预期状态 |
| 双旋拖布 | 拖布支架未卡紧、拖布缠绕或地毯受潮时不要强行运行；清洁和拆装前停止任务并断电 |
