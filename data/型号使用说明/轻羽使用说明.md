# S8-AIR 轻羽使用说明

## 1. 型号定位

| 项目 | 说明 |
| --- | --- |
| 型号 | S8-AIR 轻羽 |
| 项目内建议价格 | 1999 元 |
| 已确认功能 | 轻薄机身、基础扫拖、边角清洁优化 |
| 适合场景 | 60 平方米以内、小户型、租住空间、预算有限的日常维护 |
| 使用重点 | 保持通道通畅、按房间定时清扫、及时清理尘盒与拖布 |

轻羽的定位是小空间日常清洁，不应用“轻薄”推导为可进入所有低矮空间。沙发、床底或柜底的高度是否适配，应以实际可通过的空间和机身尺寸为准。

## 2. 组件与功能

| 组件/功能 | 用途 | 使用要点 |
| --- | --- | --- |
| 紧凑机身 | 提升小户型通行灵活性 | 首次运行观察狭窄区域是否会卡住，必要时设置禁区 |
| 主刷、边刷和吸口 | 日常扫灰、收集碎屑和边角灰尘 | 边角清洁优化不能替代人工清理死角；边刷磨损会直接影响效果 |
| 尘盒与滤网 | 收集灰尘 | 小空间也应按使用频率清理，满尘会造成吸力下降和回流 |
| 基础拖地组件 | 完成轻度湿拖 | 木地板使用低水量，地面有积水或黏性污渍时先人工处理 |
| 充电座和触点 | 回充与供电 | 底座不要放在门后、地毯边缘或狭窄死角 |

## 3. 推荐使用方式

1. 先收纳数据线、充电线、袜子、纸巾和小件玩具，尤其是租住空间常见的地面线缆。
2. 完成设备配对后，先在有人看管下完成一次全屋运行，记录容易卡住的位置。
3. 按房间或时段设置任务。卧室可优先安排在无人休息时，厨房和玄关建议在垃圾、积水处理后再运行。
4. 需要拖地时使用洁净拖布和适量清水；若地面为木地板或复合地板，使用低水量并保持通风。
5. 每次任务后清理尘盒与毛发，避免因“小户型灰尘少”而长期不维护。

## 4. 电池与充电

| 项目 | 使用说明 |
| --- | --- |
| 容量和续航 | 未在型号目录中确认，以设备铭牌、控制端显示和正式规格书为准 |
| 充电习惯 | 任务结束后回到底座，保持底座供电；不要使用不匹配的适配器 |
| 低电量回充 | 发现任务中频繁回充时，先检查清扫模式、地面阻力和电池健康提示，不以单次任务判断电池损坏 |
| 安全底线 | 电池鼓包、持续发热、无法开机或充电触点烧蚀时立即停用 |

## 5. 维护建议

| 频率 | 操作 |
| --- | --- |
| 每次使用 | 倒掉尘盒垃圾，摘除主刷和边刷毛发；拖地后拆下并清洗拖布 |
| 每周 | 擦拭传感器、充电触点和防撞条；检查轮组是否卷入头发、地毯纤维 |
| 每月 | 检查滤网状态和边刷磨损，确认底座电源线没有被挤压或反复碾压 |

## 6. 常见问题与处理

| 现象 | 先检查 | 可执行处理 | 停止使用/联系售后条件 |
| --- | --- | --- | --- |
| 狭窄区域频繁卡住 | 家具底部高度、门槛、地毯边和线缆 | 移除障碍，将区域设为禁区或调整家具间距 | 轮组卡死、底盘受损时 |
| 边角仍有灰尘 | 边刷是否磨损、是否有毛发缠绕 | 清洁或更换边刷，安排沿边或定点补扫 | 边刷不转或电机异响时 |
| 拖地水痕明显 | 拖布是否脏、出水是否偏多、地面材质 | 清洗拖布，调低水量，木地板改为低水量/仅扫地 | 水箱渗漏、地面持续积水时 |
| 吸力变弱 | 尘盒、滤网、吸口和主刷 | 清理堵塞物，滤网完全晾干后再安装 | 清理后仍无吸力或有焦味时 |
| 无法配对或控制 | 手机网络、设备配网状态、控制端版本 | 按设备提示重新配网，重启设备和路由器 | 多次失败并伴随硬件报错时 |
| 无法充电 | 底座电源、触点、轮组是否未停稳 | 擦拭干燥触点，重新摆正底座和机器人 | 触点变色、发热或反复断充时 |

## 7. 型号专属安全使用

通用电气、电池、进水和儿童宠物规范见[通用安全与维护规范](通用安全与维护规范.md)。轻羽面向小空间，应特别注意：

| 风险点 | 安全要求 |
| --- | --- |
| 紧凑空间 | 床底、桌椅腿和窄门口先进行一次有人看管的通行测试；无法稳定脱困的区域应设置禁区 |
| 租住空间线缆 | 地面常见的排插线、耳机线和充电线必须收纳，不能假设设备会完全识别细线 |
| 轻度湿拖 | 小空间通风差时避免高水量连续拖地；地板边缝、插座附近和地垫下有潮气时不要启动湿拖 |
| 低噪任务 | 低噪并不等于可以在睡眠中无监督运行；夜间任务只在地面整理完毕且充电路径明确时启用 |
