# ZENMOP 耗材与更换指南

## 1. 耗材作用与判断

| 耗材 | 作用 | 需要清洁/检查的信号 | 更换判断 |
| --- | --- | --- | --- |
| 主刷/滚刷 | 将灰尘、毛发卷入吸口 | 缠绕、打滑、变形、刷毛明显磨损 | 清理后仍打滑、变形或无法转动 |
| 边刷 | 将边角灰尘扫向吸口 | 刷毛缠绕、缺失、变形、不转 | 刷毛明显变短、断裂或电机持续报错 |
| 滤网 | 过滤尘盒排出空气 | 吸力下降、风机声变大、堵塞提示 | 破损、变形、清洁后仍堵塞；必须完全干燥后再装回 |
| 拖布 | 承载湿拖污渍 | 发硬、异味、掉毛、水痕 | 清洗晾干后仍有异味、变形或无法贴合 |
| 集尘袋 | 收集自动集尘的灰尘 | 满袋提示、集尘变慢、漏灰 | 达到设备提示或发现破损、漏灰 |
| 水箱密封件 | 防止清水/污水渗漏 | 水箱边缘潮湿、滴漏、密封圈移位 | 破损、老化或更换后仍渗漏需售后 |

## 2. 型号差异

| 型号 | 重点耗材/部件 | 维护重点 |
| --- | --- | --- |
| S8-LUNA 皓月 | 集尘袋、滤网、拖布 | 集尘通道和热风烘干口保持畅通 |
| S8-AIR 轻羽 | 滤网、主刷、边刷、拖布 | 小空间高频运行，避免尘盒长期满载 |
| X9-OBSIDIAN 曜石 | 双旋拖布、水路密封件、滤网 | 每次拖地后处理拖布和水路，检查上下水接口 |
| X9-EDGE 曜石 Edge | 主刷、边刷、滤网 | 宠物毛发和地毯纤维需优先清理 |
| M6-TERRA 霞陶 | 高扭矩滚刷、拖布、水箱密封件 | 按地面材质控制湿拖，检查滚刷负载 |
| M6-MINI 小径 | 主刷、边刷、滤网、拖布 | 定时任务前后检查耗材，避免无人任务中途卡困 |

## 3. 更换流程

1. 停止任务，把设备放在平整干燥处并断开充电连接。
2. 按设备结构取下耗材，不用硬拽卡扣或用尖锐工具撬动水路、传感器和电机。
3. 安装与型号匹配的原装或明确兼容配件，确认卡扣、密封圈、拖布支架和滤网方向正确。
4. 完成低风险空载测试，再运行小范围清扫；观察异响、漏水、吸力和回充状态。
5. 在维护记录中登记更换日期、部件和异常现象，便于后续判断性能变化。

## 4. 禁止做法

不得把未晾干的滤网装回，不得用水冲洗未标明可水洗的尘盒/电气件，不得混用不同型号的滚刷、拖布支架、密封圈或电池。型号不确定时，以包装清单和正式配件编号为准。
