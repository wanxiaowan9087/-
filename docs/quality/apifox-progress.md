## 当前已知限制

- Apifox CLI 无法读取桌面端环境的“本地值”令牌，因此 CLI 运行会得到 `401`；最终验证应在桌面端选用“本机 Docker 联调”环境执行。
- Apifox 的在线 27/27 报告是人工验收补充。因“导出数据运行”在 CLI 2.2.8 与桌面端均不可用，经用户于 2026-07-29 明确同意，唯一质量门禁改由 `backend/tests/test_api_scenarios.py` 运行同名的九组 HTTP 场景；详见 `tests/apifox/README.md`。
- APIFOX-006、007、008 的在线场景会改变本地测试数据。再次运行前执行 `./scripts/reset_apifox_local_fixtures.ps1` 重置本地种子；该重置不会上传到远程仓库，也不会影响真实用户数据。
- `429` 和 `503` 仅写入了 OpenAPI 响应契约，当前运行时没有可验证的限流器或故障注入机制，不能声称已完成覆盖。
