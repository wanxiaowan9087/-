# QA phase A: contract assets and pre-integration review

## Scope

Prepared implementation-independent QA assets for frozen OpenAPI v1, SSE,
error/authorization behavior, memory and audit semantics, frontend state, RAG
gates, and Apifox black-box scenarios. The assets are intentionally not an
acceptance result: all blocking checks must be bound and executed at the final
integration SHA.

1. Bind every `tests/qa/*.json` ID to executable pytest/Playwright/RAG tests.
2. Import OpenAPI into Apifox and retain every manifest assertion in an offline

3. Run the unique quality gate twice on a clean checkout of the final SHA. Any
   failure, skip, missing report, source change, or new commit invalidates the
   result.
