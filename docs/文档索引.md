## 推荐维护顺序

1. 先更新型号目录和功能对照表，再修改型号专属说明。
2. 发生新增、修订或停用时，更新正式导入清单和冲突记录。
3. 为每个新增结论补充评测样本与引用支持标注。
4. 运行 `python -m backend.scripts.ingest_knowledge --manifest <清单> --dry-run`，再运行 `python -m evals.run_rag_eval --assert-gates`。
5. 通过完整质量门后，按上线运维手册记录代码 SHA、清单版本、评测结果和发布/回滚结论。

## 版本原则

文档正文、正式清单、评测集和代码变更应可相互追溯。禁止直接覆盖历史清单、删除失败评测样本或用未核验的厂商宣传参数替代正式规格。
